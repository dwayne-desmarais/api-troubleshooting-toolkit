# API Troubleshooting Toolkit

A Python command-line utility for testing REST APIs,
inspecting responses, measuring response times,
and logging troubleshooting information.

## Features

- GET request testing
- Response timing
- HTTP status codes
- JSON formatting
- Header inspection
- Logging

## Technologies

- Python
- Requests
- JSON
- REST APIs

## Future Enhancements

- POST support
- Authentication
- Retry logic
- CSV export
